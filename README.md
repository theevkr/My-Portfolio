
# 🌐 Personal Portfolio Website - Vivek Raj

Welcome to my **Personal Portfolio Website**. This responsive and interactive web page showcases my educational background, skill set, projects, and contact information.

## 📌 Overview

This is a single-page portfolio website developed using **HTML**, **CSS**, and **JavaScript**. It serves as an online resume and a showcase of my skills, academic background, certifications, and projects.

## 🚀 Features

- **Responsive Layout**: Optimized for desktop and mobile devices.
- **Navigation Sidebar**: Sticky, stylish vertical navbar for quick access.
- **Home Section**: Introduction with dynamic typing effect.
- **About Section**: Personal and academic details with animated counters.
- **Education Section**: Timeline of academic journey.
- **Skills Section**: Visual skill bars with animation.
- **Projects Section**: Live project links including:
  - Calculator
  - Tic Tac Toe Game
  - Gaming Website
  - YouTube Clone
  - Learning Website
- **Contact Section**: Includes email, phone, location, and contact form.
- **Back to Top Button**: Visible on scroll for better navigation.

## 🛠️ Tech Stack

- **HTML5** - Structure of the webpage
- **CSS3** - Styling, animations, and responsive design
- **JavaScript (ES6)** - DOM interaction and event handling
- **Libraries Used**:
  - [Typed.js](https://github.com/mattboldt/typed.js) - Dynamic typing effect
  - [AOS (Animate on Scroll)](https://michalsnik.github.io/aos/) - Scroll animations
  - [Font Awesome](https://fontawesome.com/) - Icons
